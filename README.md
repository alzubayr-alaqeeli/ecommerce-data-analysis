# E-Commerce Data Analytics & Revenue Trends

## Project Overview

This project performs an exploratory data analysis (EDA) on e-commerce sales data, focusing on data cleaning, revenue calculation, category performance, top product performance, and monthly and daily revenue trends.

## Technologies Used

* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib
* **Environment:** Jupyter Notebook / Visual Studio Code

## Project Structure

* `ecommerce_analytics.ipynb`: Main Jupyter Notebook containing data cleaning, data processing, analysis, and visualizations.
* `data_processing.py`: Python script containing data cleaning and analytical routines.
* `raw_ecommerce_data.xlsx`: Raw e-commerce order dataset.

## Key Insights

* Cleaned and standardized text, date, and numerical data.
* Handled missing product prices using product-level and overall median values.
* Identified duplicate order IDs for data quality checking.
* Calculated total revenue using quantity and price.
* Analyzed revenue by category and identified the top 5 products by revenue.
* Analyzed monthly revenue trends using Matplotlib.
